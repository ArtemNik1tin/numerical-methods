# Отчёт по заданию 1

## 1. Математическая задача
Программа находит корни уравнения $f(x) = 0$ на отрезке $[A, B]$ с заданной точностью $\varepsilon$. Также решается задача о погружении шара (поиск глубины $d$).

## 2. Численные методы
- Метод бисекции (половинного деления)
- Метод Ньютона (касательных)
- Модифицированный метод Ньютона
- Метод секущих

## 3. Исходные параметры и ввод
Параметры вводятся с клавиатуры:
- Тестовая задача: отрезок $[A, B]$, число разбиений $N$, точность $\varepsilon$
- Задача о шаре: радиус $r$, плотность $\rho$, точность $\varepsilon$

## 4. Язык и типы данных
- Язык: Rust
- Базовые типы: `f64` (числа с плавающей точкой), `usize` (счётчики), `Vec` (векторы)
- Пользовательские типы: `MethodResult`

## 5. Тестовая задача

### 5.1 Постановка
$f(x) = x - 10\sin(x) = 0$ на отрезке $[-5; 3]$, $\varepsilon = 10^{-6}$.

### 5.2 Тип метода
Все методы — итерационные (приближенные). Условие остановки:
- Бисекция: длина отрезка $\leq 2\varepsilon$
- Ньютона/мод. Ньютона/секущих: $|x_{m} - x_{m-1}| \leq \varepsilon$

### 5.3 Нюансы реализации
- Защита от деления на ноль (производная в методе Ньютона, знаменатель в секущих)
- Ограничение максимального числа итераций (`MAX_ITERATIONS = 1000`)

### 5.4 Проверка результатов
- Вычисление невязки $|f(x_m)|$
- Проверка, что корень принадлежит искомому отрезку
- Сравнение результатов всех четырёх методов

### 5.5 Исходные параметры
- $f(x) = x - 10\sin(x)$
- $[A, B] = [-5; 3]$
- $\varepsilon = 10^{-6}$

### 5.6 Результаты
Программа выводит для каждого метода: начальное приближение, число шагов, корень, $|x_m - x_{m-1}|$, невязку.
