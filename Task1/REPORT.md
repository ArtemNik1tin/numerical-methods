# REPORT.md

## 1. Какую математическую задачу решает программа?

Программа решает задачу нахождения корней уравнения `f(x) = 0` на отрезке `[A, B]` с точностью `ε > 0`.

Также программа решает задачу о погружении шара в воду.

## 2. Какие численные методы используются?

### Метод отделения корней:
- **Разделение отрезка** `[A, B]` с шагом `h = (B - A) / N`, где `N ≥ 2` — число разбиений

### Методы уточнения корней:
1. **Метод бисекции** (метод половинного деления)
2. **Метод Ньютона** (метод касательных)
3. **Модифицированный метод Ньютона**
4. **Метод секущих**

## 3. Исходные параметры задачи

### Тестовая задача:
| Параметр | Значение |
|----------|----------|
| Функция | `f(x) = x - 10·sin(x)` |
| Отрезок | `[A, B] = [-5; 3]` |
| Точность | `ε = 10⁻⁶` |
| Число разбиений | `N ≥ 2` (запрашивается у пользователя) |

### Задача о погружении шара:
| Параметр | Значение |
|----------|----------|
| Уравнение | `f(d) = 4/3·π·r³·ρ - π·d²·(3r - d)/3 = 0` |
| Отрезок | `[0; 2r]` |
| Точность | `ε = 10⁻⁶` |
| Параметры | радиус `r` (вводится), плотность `ρ` (из таблицы материалов) |

### Ввод параметров:
Все параметры вводятся с клавиатуры через интерактивное меню:
- Выбор задачи (1 или 2)
- Выбор метода (1-4)
- Концы отрезка A, B
- Число разбиений N
- Точность ε
- Номер отрезка для уточнения

## 4. Язык программирования и типы переменных

- **Язык:** Rust
- **Среда:** Cargo (стандартный сборщик Rust)
- **Типы переменных:**
  - `f64` — вещественные числа двойной точности (все вычисления)
  - `usize` — целые неотрицательные (количество шагов, номер метода, номер отрезка)
  - `String` — строки (названия материалов, сообщения)
  - `Vec<T>` — динамические массивы (отрезки, результаты)
  - `Result<T, E>` — обработка ошибок
  - `Box<dyn Error>` — типизированные ошибки

## 5. Представление тестовой задачи

### 5.1. Постановка задачи
Дано уравнение `f(x) = x - 10·sin(x) = 0` на отрезке `[-5; 3]`. Требуется найти все корни нечетной кратности с точностью `ε = 10⁻⁶`.

### 5.2. Точный или приближенный метод/Условия остановки итерационных процедур
Все используемые методы являются **приближенными** (итерационными).

| Метод | Условие остановки |
|-------|------------------|
| Бисекция | `b - a ≤ 2ε` |
| Ньютон | `\|xₖ - xₖ₋₁\| ≤ ε`  |
| Модифицированный Ньютон | `\|xₖ - xₖ₋₁\| ≤ ε` |
| Секущие | `\|xₖ - xₖ₋₁\| ≤ ε` |

Дополнительно: максимальное число итераций `MAX_ITERATIONS = 1000` для защиты от зацикливания.

### 5.3. Нюансы реализации

| Проблема | Решение |
|----------|---------|
| Деление на ноль (метод Ньютона) | Проверка `df(x) == 0.0` перед делением |
| Деление на ноль (секущие) | Проверка `f(x₁) == f(x₀)` перед делением |
| Зацикливание | Ограничение `MAX_ITERATIONS = 1000` |
| Ошибка округления | Использование `f64` |
| Некорректный ввод | Валидация всех параметров с сообщениями об ошибках |
| Отсутствие корня на отрезке | Проверка смены знака `f(a)·f(b) ≤ 0` |
| NaN/Infinity | Проверка значений функции на каждом шаге |

### 5.4. Проверка правильности решения

1. **Проверка невязки:** вычисление `|f(xₘ)|` порядка `ε` или меньше
2. **Проверка принадлежности отрезку:** корень должен лежать в исходном отрезке `[a, b]`
3. **Сравнение методов:** все 4 метода должны давать близкие значения корня

### 5.5. Исходные параметры тестовой задачи

```
Функция: f(x) = x - 10·sin(x)
Отрезок: [A, B] = [-5; 3]
Точность: ε = 10⁻⁶
Число разбиений: N = 100 (рекомендуется)
```

### 5.6. Результаты работы программы

При запуске с параметрами `N = 100`, `ε = 10⁻⁶`:

```
Найдено 3 отрезков перемены знака с шагом h=0.08
Отрезок 1: (-2.92, -2.84)
Отрезок 2: (-0.04, 0.04)
Отрезок 3: (2.84, 2.92)
```

**Уточнение корня на отрезке 1** `[-2.92; -2.84]`:

| Метод | Шаги | Корень | \|xₘ - xₘ₋₁\| | Невязка |
|-------|------|--------|--------------|---------|
| Бисекция | 16 | -2.85234191894531 | 1.22e-6 | 2.59e-7 |

**Анализ результатов:**
- Метод бисекции гарантированно сходится, но требует больше итераций (линейная сходимость)
- Метод Ньютона сходится быстрее (квадратичная сходимость), но требует вычисления производной
- Модифицированный метод Ньютона проще в реализации (производная вычисляется один раз), но медленнее
- Метод секущих не требует производной, имеет сверхлинейную сходимость
