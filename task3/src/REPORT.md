### 1. Какую математическую задачу позволяет решить Ваша программа?
Программа решает задачу **численного дифференцирования**. Она предназначена для нахождения f' и f'' функции, заданной таблично, с порядками погрешности O(h^2) и O(h^4).

### 2. Какой/какие численные методы Вы используете для нахождения решения?
* Для первой производной с точностью $O(h^2)$: односторонние формулы для границ (4) и (5) и для внутренних узлов (3).
* Для первой производной повышенной точности $O(h^4)$: формулы (7)–(11).
* Для второй производной с точностью $O(h^2)$: формула (6).

### 3. Каковы исходные параметры задачи? Как осуществляется ввод?
* **Исходные параметры:**
  1. Выбор тестовой функции из 4 вариантов (полином 2-й степени, полином 3-й степени, быстро растущая экспонента, тригонометрическая функция).
  2. Количество точек в таблице.
  3. Начальная точка $x_0$.
  4. Шаг $h > 0$.
* **Способ ввода:** ввод с клавиатуры.

### 4. На каком языке написана программа и какие типы используются?
* **Язык программирования:** Rust.
* **Типы переменных:** Используется тип данных с плавающей точкой двойной точности (`f64`)
### 5. Представление тестовой задачи
1. **Задача и методы:** Приближенное вычисление производных таблично заданной функции.
2. **Характер метода:** Методы неитерационные, условия остановки и итерационные циклы отсутствуют.
3. **Нюансы реализации:** Проверка на минимальное число точек (m >= 4).
4. **Проверка правильности:** Сравнение приближенных значений с «точными» значениями производных.
5. **Параметры тестовой задачи:** Например, функция $f_1(x) = 2x^2 - 3x + 1$, начальная точка $x_0 = 0.0$, шаг $h = 0.1$, количество точек $m+1 = 6$.
6. **Анализ результатов:** Формулы с порядком $O(h^4)$ обеспечивают более высокую точность приближения по сравнению с $O(h^2)$.
